Project overview

One visual identity across slides and pages.

The goal was to show how a single brand system, navy, white and orange with clear type and generous spacing, can carry through very different deliverables: business, educational and marketing presentations, plus proposals, reports, a company profile, a CV template and a project report.

Every file here is real and downloadable. Charts in the PowerPoint files are native and editable, and the PDFs use real text you can select and copy.

Design process

From brief to polished file.

01 / BRIEF

Define the message

Audience, goal, required sections and tone for each deliverable.

02 / STRUCTURE

Outline and layout

One idea per slide or page, with a shared grid and type scale.

03 / DESIGN

Build the visuals

Charts, icons and diagrams in one palette, with spacing checked.

04 / CHECK

Verify and export

Files validated, rendered and reviewed page by page before delivery.

Tools & techniques

How the files were made.

PRESENTATIONS

Generated as standard .pptx files with a custom theme, reusable layouts, native editable charts and icons.

PDF DOCUMENTS

Generated programmatically with real, selectable text, tables and vector charts at A4 size.

TYPOGRAPHY

Cambria and Calibri in the decks for reliable editing; Poppins and Helvetica in the PDFs.

COLOUR SYSTEM

Navy #101F39, orange #F0784B and white, with soft tints for cards and notes.

QUALITY CHECKS

PPTX schema validation, slide rendering and page-by-page visual review.

AI ASSISTANCE
